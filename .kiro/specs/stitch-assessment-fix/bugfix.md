# Bugfix Requirements Document

## Introduction

The wound analysis system currently has two issues affecting the quality and usability of wound assessments:

1. **Stitch Assessment Logic**: The system uses overly strict thresholds that fail to properly assess when stitches are needed. It requires BOTH length ≥ 3.0 cm AND width ≥ 0.6 cm, which misses important cases like fresh lacerations that are shorter but show clear indicators of needing closure (depth, gaping potential, high red percentage indicating fresh injury).

2. **Recommendation Formatting**: The system displays recommendations as bullet point lists instead of conversational sentences, making the feedback feel clinical and less user-friendly.

**Example Case**: A 0.93 cm x 0.36 cm fresh laceration (57.8% red, 49.4% pink) is assessed as not needing stitches, when the wound characteristics (fresh laceration, depth indicators, gaping potential) suggest it should recommend professional evaluation for closure.

**Impact**: Users receive inadequate guidance on wound closure needs and experience less engaging, harder-to-read recommendations.

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN a fresh laceration is 0.93 cm long with high red percentage (57.8%) indicating recent injury THEN the system incorrectly assesses it as not needing stitches without considering the fresh injury indicators

1.2 WHEN a wound has depth indicators (dark colors, gaping potential) but doesn't meet the strict length AND width thresholds THEN the system fails to recommend professional evaluation for closure

1.3 WHEN the stitch assessment logic evaluates a wound THEN it uses a rigid "require both" condition (length ≥ 3.0 cm AND width ≥ 0.6 cm) that ignores other important factors like laceration type, depth appearance, and fresh injury indicators

1.4 WHEN recommendations are generated by the AI feedback system THEN they are formatted as bullet point lists in the response structure

1.5 WHEN the stitch assessment provides reasoning THEN it doesn't explain the multiple factors considered (length, depth, gaping, fresh injury indicators) in a clear, understandable way

### Expected Behavior (Correct)

2.1 WHEN a fresh laceration is 0.93 cm or longer with high red percentage (>50%) indicating recent injury THEN the system SHALL assess whether stitches are needed by considering multiple factors: laceration length, depth indicators, gaping potential, and fresh injury markers

2.2 WHEN a wound shows depth indicators (dark colors >5% black or >20% brown) combined with laceration characteristics THEN the system SHALL recommend professional evaluation even if the wound doesn't meet strict size thresholds

2.3 WHEN the stitch assessment logic evaluates a wound THEN it SHALL use a multi-factor approach considering: laceration length (>1.5 cm often benefits from closure), depth appearance, gaping potential (area >3 cm² with laceration shape), and fresh injury indicators (red >50% with laceration)

2.4 WHEN recommendations are generated by the AI feedback system THEN they SHALL be formatted as conversational sentences instead of bullet point lists

2.5 WHEN the stitch assessment provides a recommendation THEN it SHALL include clear reasoning explaining which factors (length, depth, gaping, fresh injury) contributed to the assessment

### Unchanged Behavior (Regression Prevention)

3.1 WHEN a wound is a small surface abrasion with high pink percentage (>30%) indicating epithelialization THEN the system SHALL CONTINUE TO correctly assess it as not needing stitches

3.2 WHEN a wound has area < 1.0 cm² and length < 2.5 cm THEN the system SHALL CONTINUE TO assess it as a small superficial wound not requiring stitches

3.3 WHEN a wound meets the severe criteria (length ≥ 3.0 cm AND width ≥ 0.6 cm) THEN the system SHALL CONTINUE TO recommend stitches/closure

3.4 WHEN a wound has extreme gaping (width ≥ 0.8 cm) THEN the system SHALL CONTINUE TO recommend stitches/closure

3.5 WHEN the AI feedback system generates other assessment fields (healing_stage, severity, infection_risk, etc.) THEN the system SHALL CONTINUE TO format them according to their existing structure

3.6 WHEN recommendations include warning signs, immediate care steps, or medication lists THEN the system SHALL CONTINUE TO provide comprehensive safety information
